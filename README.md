## 🚀 Funcionalidades por Nivel

* **Nivel 1 · Base (Obligatorio):** 
  * Portada interactiva y navegación clara.
  * Estructura basada en componentes de datos dinámicos (`data/modulos.js`)[cite: 11].
  * Fichas detalladas con instrumentos, programas, herramientas y recursos verificados[cite: 11].
  * Diseño adaptable a dispositivos móviles (Responsive)[cite: 11].
  * Publicado y verificado en GitHub Pages[cite: 11].

* **Nivel 2 · Pro (Interactividad):** 
  * Buscador y filtros en tiempo real por palabra clave y docente[cite: 11].
  * Guardado de progreso de repaso utilizando la API de `localStorage`[cite: 11].
  * Quiz interactivo por módulo con retroalimentación inmediata[cite: 11].
  * Conmutador de modo claro y modo oscuro[cite: 11].
