# HUB de Repaso

Versión actual: **v0.5**

Sitio publicado: https://carlooos503.github.io/portal-repaso/

## Contenido

- Los 8 módulos se cargan dinámicamente desde `data/modulos.js`: 4 de Javier Mineros y 4 de Arcides Canales.
- Cada módulo se puede desplegar para consultar sus instrumentos, programas, herramientas, entregas de Classroom y recursos.
- La interfaz usa un tema negro y dorado adaptable a pantallas móviles.
- El buscador y el filtro por docente actualizan la lista al instante.
- El progreso de módulos repasados, los resultados correctos del quiz y el tema seleccionado se guardan en el navegador.
- Cada módulo incluye un quiz con retroalimentación inmediata, y el tema claro/oscuro se puede cambiar desde la página.

Para revisar el sitio localmente, abre `index.html` en un navegador.
